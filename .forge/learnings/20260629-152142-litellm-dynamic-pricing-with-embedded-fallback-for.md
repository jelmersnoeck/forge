# Learnings - 2026-06-29 15:21

- The litellm price table (model_prices_and_context_window.json) is MISSING several older Claude dated IDs forge references: claude-3-5-sonnet-20241022, claude-3-5-sonnet-20240620, claude-3-sonnet-20240229, claude-3-5-haiku-20241022. It also lacks the worker's old bogus haiku alias claude-haiku-4-20250506. So a pure litellm swap breaks those — keep a small supplementalPricing map in internal/runtime/cost/cost.go for litellm gaps, consulted after the litellm table.
- litellm costs are per-SINGLE-token USD (e.g. input_cost_per_token: 3e-06 = $3/1M); forge's Pricing struct is per-1M, so multiply each litellm value by 1e6 on load. Cache fields can be null (OpenAI) -> decode to 0. Skip the non-model 'sample_spec' key and any entry with no input/output token cost.
- internal/runtime/cost package tests hit the network on first Calculate() because resolvePricing fires a sync.Once-guarded litellm fetch. Make tests deterministic by adding a TestMain that sets LITELLM_MODEL_COST_MAP_URL to an unreachable URL (http://127.0.0.1:1/offline) + an isolated HOME, forcing the embedded-snapshot fallback. Per-test offline override also works via t.Setenv before the once fires.
- Model aliases live in TWO places that must stay in sync: internal/agent/worker.go modelAliases (map) and cmd/forge/cli.go modelAliasesForDisplay ([][2]string). Both had the bogus haiku target. Add a CI guard test (TestModelAliasesArePriced) asserting every alias target resolves via cost.LookupPricing to non-zero input/output price.
